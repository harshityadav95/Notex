# Notex course notebook artwork

Created with the built-in ImageGen tool, October 2026. These are original Notex cover
illustrations, not book covers from the publishers or artwork downloaded from Fanout.
The reference was `web/assets/notebook-sprite-transparent.png`, used for style only.
Both final files are 1254 × 1254 PNGs with true alpha and subtle contact shadows.

## Go — `go-notebook.png`

Final prompt: Create one isolated muted cyan-teal Notex hardcover notebook, using the
supplied nine-book sprite solely as a style reference. Match photographic cloth/leather
grain, rounded corners, narrow left spine, small right tab, nearly front-facing
perspective, fine engraved technical drawings, contact shadow, and editorial typography.
Title exactly “Learning Go” in large black serif on two lines; tiny “notex” bottom left.
Cover art shows a slice backing array, pointer arrows, braces, and restrained plotting
dots, printed directly on the cover. Entire uncut book centered on a square transparent
canvas. No sticker, grid paper, sprite sheet, extra books, Fanout branding, mascot,
or watermark.

## DDIA — `ddia-notebook.png`

Final prompt: Match the supplied Notex notebooks’ texture, lighting, spine, serif
typography, and proportions. One dusty sage/olive hardcover titled “Data-intensive
applications,” small “notex” at bottom left, fine engraved line art of three connected
database cylinders with replication paths, a narrow left spine and small right tab,
rounded corners, and subtle technical markings. Entire book isolated on a true
transparent square background with a subtle contact shadow. No sticker, grid-paper
approximation, Fanout branding, or extra objects. Reference is used for style only.

Delivery copies (`go-notebook.webp` and `ddia-notebook.webp`) use WebP quality 86 at
the original dimensions with alpha preserved. The website loads these compressed
copies; the original generated PNGs are retained as source artwork.
