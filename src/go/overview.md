# Go study notes

Build fluency in Go through composite types, control flow, functions, pointers, and testing.

## Study goals

- Understand the behavior of arrays, slices, maps, and structs.
- Reason about scope, function calls, and memory sharing.
- Practice testing, fuzzing, benchmarking, and concurrent code analysis.

## Learning method

Follow the numbered modules, run the examples, and complete the practice lessons. Use the recap to review each topic and mark lessons as understood when you can explain the mechanism in your own words.
