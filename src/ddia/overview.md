# Data-intensive applications

Study the mechanisms and trade-offs that shape reliable data systems.

## Study goals

- Connect requirements with data models and storage choices.
- Reason about replication, sharding, transactions, and consensus.
- Compare batch and stream processing approaches.
- Evaluate correctness, failure recovery, and responsible data use.

## Learning method

Start with the study guide and follow the numbered modules. Trace an ordinary request and a failure scenario for each mechanism, then summarize its assumptions and trade-offs.
