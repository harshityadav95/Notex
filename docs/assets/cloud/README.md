# Cloud path artwork

Original notebook illustrations generated for Notex on 2026-10-24 using the built-in
image generation tool. The existing Notex notebook sheet supplied the visual style:
tactile paper, rounded covers, index tabs, engraved technical drawings, and soft shadows.

- `cloudflare-notebook.png`: apricot notebook with a globe and edge-network diagram.
- `azure-notebook.png`: blue notebook with cloud and server architecture.
- `kubernetes-notebook.png`: lavender notebook with connected container nodes.

Each transparent PNG is 800 × 800 pixels and is served locally. The full-resolution
originals remain in the generation output directory. The artwork uses Notex branding;
it does not reproduce Fanout illustrations or official vendor logos.
