Cloudflare at the edge

Start with the network. Then bring your code, data, and applications closer to the people using them.

  1. Understand the edge

    Trace a request through DNS, the network, and the cache.

  2. Build with Workers

    Explore request handlers, bindings, and local development.

  3. Choose your storage

    Get oriented with R2 object storage, D1, and Durable Objects.

  4. Connect the pieces

    Follow an official tutorial from your first request to deployment.

Build with Azure

Build a mental model of the cloud, from your first resource group to the services that keep an application running.

  1. Learn the foundations

    Explore subscriptions, resource groups, regions, and cloud concepts.

  2. Run your application

  3. Connect and protect

    Get familiar with virtual networks, Microsoft Entra ID, and access control.

  4. Operate with confidence

    Explore monitoring, deployment workflows, and cost management.

CONTAINERS & CLUSTERS / PATH PREVIEW

Kubernetes in practice

Go from a container to a running system. Understand the objects, the control loop, and what happens inside a cluster.

  1. Meet the cluster

    Understand nodes, the control plane, and the desired-state model.

  2. Deploy a workload

    Work through Pods, Deployments, labels, and configuration.

  3. Expose and connect

    Explore Services, service discovery, and persistent storage.

  4. Keep it running

    Follow the official basics: inspect, scale, and update an application.

A starting map for your learning. Continue with the official guides and tutorials.

FAQ

Questions people
ask before starting.

Where should I start?

Start free. If you want programming fundamentals, open Python. For architecture and tradeoffs, open System Design. To find a particular topic, search the library.

What is inside the library?

Programming notes, system design, database references, developer tools, algorithms, handwritten PDFs, and Python notebooks. Everything comes from the existing Notex collection.

Is this only for interview prep?

No. Use the notes as a practical reference, work through examples, or follow your own curiosity. The interview study plan is one part of the collection.

Can I use it without paying?

Yes. All notes, notebooks, and PDFs are free. No account or subscription is needed.

Can I contribute a correction?

Yes. Use Edit on GitHub on a note, or open an issue in the repository. Notex is built in the open.

Where do my saved notes go?

They stay in this browser on your device. Open a note and select Save note, then use the Saved filter in the library.
